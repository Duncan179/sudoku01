📖 How to Play

🎯 Objective

Fill the 9×9 grid so that each row, column, and 3×3 box contains all digits from 1 to 9 without repetition.

📋 Basic Rules

  • Each row must contain digits 1-9 with no duplicates
  • Each column must contain digits 1-9 with no duplicates
  • Each 3×3 box must contain digits 1-9 with no duplicates
  • You have 3 lives (❤️) - lose one for each wrong input
  • If you lose all 3 lives, the game is over!

🎮 Controls

  • Click a cell to select it
  • 1-9 to enter a number
  • 0 or Delete to clear a cell
  • Arrow Keys to navigate
  • N to toggle Notes mode
  • Ctrl+Z to undo

💡 Features

  • Notes Mode: Add pencil marks for possible numbers
  • Hints: Reveal the correct number for selected cell
  • Undo: Take back your last move
  • Auto-highlight: See related cells and same numbers

⭐ Bonus Effects

  • Complete a row, column, or box to see special animations!
  • Wrong inputs will shake and cost you a life
  • Correct inputs will glow green
